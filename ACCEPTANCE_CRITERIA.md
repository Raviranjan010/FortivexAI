# Acceptance Criteria

- [ ] Health and safe configuration endpoints work without exposing secrets.
- [ ] Persistent isolated sessions retain bounded conversational context.
- [ ] Gemini adapter returns validated responses and surfaces provider failures.
- [ ] Voice UI implements IDLE/LISTENING/PROCESSING/SPEAKING/ERROR/ENDED plus text fallback.
- [ ] TXT/PDF documents are validated, chunked, indexed, retrieved with sources, and fully deleted.
- [ ] Validated bounded tools execute real services and log observable outcomes.
- [ ] BANT scoring is deterministic and evidence-based; sentiment is transcript-only.
- [ ] CRM supports real CRUD/search/filter/export and normalized-contact deduplication.
- [ ] Booking rejects past/out-of-hours/conflicting/unconfirmed requests and persists confirmed ones.
- [ ] Summaries and analytics use database facts only.
- [ ] Nine responsive pages have meaningful loading, empty, and error states.
- [ ] Backend suite, frontend tests, typecheck, and production build pass.
- [ ] Required operational, security, architecture, cost, and interview documentation exists.
- [ ] Live Gemini and microphone checks are explicitly reported as verified or unverified.
