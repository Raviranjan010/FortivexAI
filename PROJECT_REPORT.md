# SalesPilot AI — Autonomous AI Sales Voice Agent

Release update: the tool loop now supports bounded follow-up actions, optional Gemini embeddings cache chunk vectors, and SQLite enforces non-overlapping active bookings. Live Gemini and hardware verification remain outstanding.

Sales teams lose time to repetitive product questions, inconsistent qualification, manual CRM entry, and delayed demo scheduling. SalesPilot AI is a commercially oriented prototype that demonstrates how an autonomous sales representative can respond continuously while preserving verifiable business records. The included use case is NovaCRM, a clearly fictional B2B SaaS company with a replaceable product knowledge base.

The solution combines a responsive React and TypeScript interface with a modular FastAPI backend, SQLAlchemy, and SQLite. Customers can converse through browser speech recognition and speech synthesis in English or Hindi, or use the always-available text fallback. A consent notice precedes voice use, and raw audio is not stored. Conversation sessions, messages, extracted facts, tool events, summaries, leads, and appointments persist across restarts.

The Gemini adapter requests schema-validated responses and bounded structured tool calls. Ten registered tools support knowledge search, profile updates, deterministic BANT qualification, transcript sentiment, availability, proposals, confirmed booking, CRM persistence, and summaries. Product answers use chunk-level TF-IDF retrieval over uploaded TXT/PDF documents and return source references. Retrieved content is treated as untrusted data. The agent may propose a slot, but the backend rejects appointment creation unless confirmation is explicit; database uniqueness and transactions prevent double booking.

The implemented internal CRM provides lead creation, contact-based deduplication, search/filter APIs, deletion, CSV export, scoring evidence, and appointment association. Dashboards calculate counts, booking rate, pipeline distribution, sentiment, and average duration from database queries—never random values. Settings persist business hours, timezone, language, duration, and agent identity without exposing API keys.

Automated tests cover health/configuration safety, session isolation, scoring, CRM deduplication, document lifecycle/retrieval, file validation, booking confirmation/conflicts/past dates, summaries, analytics, and tool validation. The frontend state-machine tests and production build also pass. Live Gemini and microphone behavior remain manual checks because they require a valid credential and interactive browser hardware.

For production, static assets move to S3/CloudFront; stateless APIs run on ECS Fargate behind an ALB; PostgreSQL, Redis, SQS, Cognito, Secrets Manager, and CloudWatch provide durable, scalable, tenant-aware infrastructure. The local MVP is intentionally unauthenticated and is not represented as production secure. Future work includes OAuth/tenant isolation, managed embeddings, external CRM/calendar adapters, streaming audio, deeper E2E coverage, and measured load testing.
